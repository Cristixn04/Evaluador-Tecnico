# Pistas Progresivas - Fase CODING

**Entregado nivel 1** (bloqueo leve >3 min sin output o progreso):
- "Tómate un momento para revisar los requisitos de entrada y salida".
- "¿Has escrito la firma de la función principal?"

**Entregado nivel 2** (bloqueo moderado >5 min o errores recurrentes en tests):
- "La estructura `X` que mencionaste en la fase DESIGN podría ayudarte aquí".
- "Revisa el caso de borde: lista vacía / valor nulo / límite máximo".

**Entregado nivel 3** (bloqueo severo >10 min o frustración detectada):
- "Pista concreta: usa `collections.defaultdict` para agrupar por clave".
- "Divide la solución en dos funciones: `parse_input` y `solve_core`".

**Reglas de entrega**:
- Máximo una pista por interacción candidata-sistema.
- Esperar confirmación del candidato antes de la siguiente pista.
- Registrar el nivel usado para efecto de evaluación (menor autonomía = menor score en el rubro de "autonomía para resolver problemas").
